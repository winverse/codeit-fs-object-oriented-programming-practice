# 01. 상품 라벨 만들기 해설

`getLabel()`은 `this.name`과 `this.price`를 읽어 `스웨터(30000원)` 문자열을 만들어 반환합니다. `product.getLabel()`처럼 객체의 메서드로 호출하면 `this`는 메서드를 호출한 `product` 객체를 가리킵니다. 메서드 안에서 `product.name`처럼 객체를 담은 변수 이름을 직접 쓰면 지금은 같은 값이 출력되지만, 변수 이름을 바꿀 때 메서드 안도 함께 고쳐야 하고, 같은 함수를 다른 상품 객체의 메서드로 호출해도 계속 스웨터의 값을 읽습니다. `this`를 쓰면 어느 객체의 메서드로 호출하든 그 객체의 상태를 읽습니다.
