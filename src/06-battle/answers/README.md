# 06. 전투 객체의 책임 나누기 해설

이 구조에서는 전사 객체에 `castFireball`이 없고, 마법사 객체에 `powerStrike`가 없습니다. 두 스킬 모두 MP를 쓰지만 각 클래스가 자기 `mp`를 차감하므로, 직업별 스킬과 자원 관리 규칙을 각 클래스의 책임으로 나눌 수 있습니다. 같은 기준으로 `attack`, `powerStrike`, `castFireball`은 상대의 `hp`를 직접 바꾸지 않고 상대의 `takeDamage`를 호출하므로, 체력을 줄이는 규칙(최소 0)은 피해를 받는 쪽 클래스의 책임으로 남습니다.
