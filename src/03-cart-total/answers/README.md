# 03. 생성자 함수로 장바구니 합계 계산하기 해설

`new Cart()`로 호출하면 `this`가 새로 만들어진 객체를 가리키므로, 함수 본문에서 `this.items = []`로 장바구니마다 자기 상품 목록을 만들고 `this.addItem`과 `this.getTotalPrice`에 메서드를 넣습니다. `addItem()`은 `this.items`에 상품을 추가하고, `getTotalPrice()`는 `reduce()`로 상품 가격을 모두 더한 합계를 반환합니다. `reduce()`의 초기값 `0`을 빠뜨리면 첫 상품 객체가 누적값으로 쓰여 합계가 숫자로 계산되지 않고, 상품이 없을 때는 오류가 발생합니다. 생성자 함수는 본문 실행이 끝나면 새 객체를 자동으로 반환하므로 `return`을 쓰지 않습니다.
