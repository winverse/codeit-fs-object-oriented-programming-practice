# 07. 이름으로 계좌의 책임 드러내기 해설

각 멤버가 하는 일을 보고 이름을 붙입니다. `a`에는 constructor가 받은 계좌 주인의 이름이 들어가므로 `holder`이고, `b`에는 입금·출금·이체 때마다 더하고 빼는 금액이 들어가므로 `balance`입니다. `add`는 잔액을 늘리므로 `deposit`, `sub`는 잔액이 모자라면 `Insufficient balance`를 출력하고 아니면 잔액을 줄이므로 `withdraw`, `move`는 내 잔액을 줄이고 다른 계좌의 잔액을 늘리므로 `transfer`입니다. 이름을 바꿔도 실행 결과는 같지만, 이제 `tom.deposit(20_000)`처럼 호출부만 읽어도 각 줄이 하는 일을 알 수 있습니다. 추상화로 고른 책임이 이름으로 드러나야 다른 개발자가 구현을 따라가지 않고도 클래스를 쓸 수 있습니다.
